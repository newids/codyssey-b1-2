# 과정 개요서 — React 첫걸음: 3일 만에 메모 앱 만들기

## 한눈에 보기

| 항목 | 내용 |
| --- | --- |
| 시간 | 2시간 × 3일, 총 6시간 (매일 10분 휴식) |
| 대상 | React를 처음 접하는 사람 |
| 선수 지식 | HTML 태그를 읽을 수 있고, JavaScript의 변수·함수·배열을 한 번이라도 써 본 적이 있다 |
| 방식 | 짧은 이론(20분 이내) 뒤에 바로 실습. 3일 동안 메모 앱 하나를 단계별로 키운다 |
| 언어와 도구 | TypeScript, React 18, Vite, VS Code |
| 결과물 | 메모를 추가·삭제·검색하고, 새로 고쳐도 남아 있는 학습 메모 앱 |

## 이 과정을 마치면

1. 화면을 컴포넌트로 나누고 props로 데이터를 내려보낼 수 있다.
2. "이벤트 → state 변경 → 다시 렌더링" 흐름을 그림으로 설명할 수 있다.
3. 배열 state를 추가·삭제·수정하고 목록으로 그릴 수 있다.
4. 입력 폼을 만들고 검증 메시지를 보여 줄 수 있다.
5. `useEffect`로 저장과 데이터 요청을 처리하고, 로딩·에러·빈 상태를 나눠 그릴 수 있다.
6. 실제 서비스에서 라우팅, 전역 상태, 백엔드, 배포가 어디에 놓이는지 아키텍처 그림에서 짚을 수 있다.

TypeScript 문법은 따로 가르치지 않는다. 1일 차에 JavaScript와의 차이를 소개하고, 코드에 나오는 타입 표기를 읽는 법만 익힌다.
