## 구간별 진행

### 도입 (8분)

- 완성본을 1분 시연한다: 메모 추가 → 별 누르기 → 검색 → 새로 고침해도 남아 있음 → 아래 팁 영역.
- "3일 뒤에 이 코드를 읽고 설명할 수 있게 되는 것이 목표"라고 말한다. 타이핑 속도는 중요하지 않다는 점을 분명히 한다.
- 질문: "React를 써 본 적은 없어도 들어 본 적은 있나요? 어디서?"

### 이론 1 — React가 필요한 이유 (14분)

- 전체 구조 그림(G1)에서 "오늘부터 3일은 이 상자 안"이라고 범위를 짚는다. 백엔드·배포는 3일 차에 다시 본다고 예고만 한다.
- DOM 직접 조작 코드는 읽어 주기만 한다. 요점은 "고칠 곳이 3군데인데 하나를 빠뜨리면?"이다.
- 비교 그림(G3)에서 아래쪽(React) 흐름을 손으로 따라가며 "우리는 state만 바꾼다"를 말한다.
- 마지막 슬라이드의 한 문장("화면은 데이터로부터 계산된다")을 같이 읽는다. 3일 내내 이 문장으로 돌아온다.

던질 질문: "좋아요 숫자가 화면 세 군데에 보인다면, 직접 고치는 방식에서는 코드를 몇 군데 고쳐야 할까요?"

### 이론 1-2 — JavaScript와 TypeScript (8분)

- 8분을 넘기지 않는다. 문법 설명을 하지 않는다.
- 전할 것은 세 가지다: (1) JavaScript에 타입 표기를 더한 것 (2) 실행 전에 오류를 알려 준다 (3) 브라우저에서는 JavaScript로 바뀌어 돌아간다.
- G2 그림에서 "타입 검사" 상자를 짚고 "빨간 밑줄은 여기서 나온다"고 말한다.
- "타입은 가이드에 적힌 대로 쓴다. 읽을 수 있으면 된다"를 분명히 한다.

예상 질문

- "JavaScript로 하면 안 되나요?" → 된다. 다만 실무 프로젝트 대부분이 TypeScript이고, AI 도구가 만든 코드도 TypeScript인 경우가 많아 읽을 줄 알아야 한다.
- "타입을 틀리면 실행이 안 되나요?" → 개발 서버에서는 실행된다. 빌드할 때 막힌다. 실습 0에서 직접 확인한다.

### 실습 0 (13분)

- 같이 진행한다. 강사 화면으로 1–3단계를 보여 주며 따라오게 한다.
- 4단계(오류 내 보기)는 꼭 한다. 빨간 오류 창을 미리 본 사람은 나중에 덜 당황한다.
- 8분 시점에 실행이 안 되는 사람을 파악해 조교가 붙는다.

### 이론 2 — JSX와 컴포넌트 (14분)

- JSX 규칙은 `App.tsx`를 열어 실제 코드에서 짚는다: 바깥 태그 하나, `className`, 중괄호.
- 라이브 코딩(3분): `App.tsx` 안에 `function Hello() { return <p>안녕하세요</p>; }`를 만들고 `<Hello />`를 세 번 쓴다. 소문자 `<hello />`로 바꿔 화면에서 사라지는 것을 보여 준다.
- 컴포넌트 트리 그림(G4)을 띄우고 시작 화면 캡처와 나란히 놓아 "어느 상자가 어느 부분인지" 묻는다.

던질 질문: "이 화면에서 반복되는 덩어리는 무엇인가요?" (카드)

### 실습 1 (23분)

- 1–2단계(`Header`)는 같이 하고, 3–5단계는 각자 한다.
- 15분 시점에 절반 이상이 4단계에 못 갔으면 `NoteCard`까지 같이 진행한다.
- 끝날 때 "카드 3장이 똑같죠? 왜일까요?"로 이론 3에 연결한다.
- 흔한 오류: import 경로, 소문자 컴포넌트 이름, `export default` 누락.

### 이론 3 — props와 목록 (10분)

- "함수에 인자를 넘기는 것과 같다"로 시작한다.
- props 흐름 그림(G5)에서 화살표가 아래로만 있는 것을 짚는다.
- 타입 슬라이드는 실제로 보여 준다: `<NoteCard />`에 빨간 밑줄 → `note={…}`를 넣으면 사라짐.
- `map`은 자가 점검에서 본 `numbers.map((n) => n * 2)`와 같은 것이라고 연결한다.

### 실습 2 (15분)

- 2단계 뒤에 빨간 밑줄이 생기는 것은 가이드에 예고돼 있다. "밑줄이 생겼다면 잘하고 있는 것"이라고 말해 준다.
- 6단계(데이터 추가)를 꼭 하게 한다. "컴포넌트를 안 고쳤는데 화면이 바뀐다"가 오늘의 핵심 경험이다.
- 시간이 모자라면 5단계(`Header` props)를 건너뛰고 6단계를 먼저 한다.

### 정리 (5분)

- 정리 표를 한 줄씩 읽고, 수강생 한두 명에게 "컴포넌트를 한 문장으로?"를 묻는다.
- 과제 안내: React Playground 레슨 1, 2와 퀴즈. 내일 시작할 때 5문항 퀴즈가 있다고 알린다.
- 못 끝낸 사람: 내일 `npm run checkpoint lab2`로 맞춰서 시작한다고 안내한다.
